## Description
This project focuses on rag q&a system. It aims to provide a robust, efficient, and scalable solution using modern technologies and best practices in the field.

## Key Features
- High performance architecture
- Extensible and modular design
- Comprehensive data processing capabilities
- Easy-to-use interface and quick setup

## Tech Stack
- LangChain\n- FAISS\n- Embeddings\n- Streamlit

## Quick Start
```bash
git clone https://github.com/iMuneebK/RAG-DocQA-LangChain.git
cd RAG-DocQA-LangChain
pip install -r requirements.txt
python main.py
```
